# Cydia Repository

This is the source code/hosting repository for my Cydia repository. It contains the necessary files to host tweaks or packages for jailbroken iOS devices.

## 🌐 Repository URL
You can add this repository to your Cydia or Sileo package manager using the following link:
**[https://dervicblog.github.io/repo/](https://dervicblog.github.io/repo/)**

## 🚀 Repository Contents
* **Packages:** This repository serves as a host for various packages/tweaks.
* **Depictions:** Custom depictions for better presentation of the packages.
* **Assets:** Includes icons and styling (CSS/JS) for the repository's web interface.

## 🛠️ How to use
1. Copy the repository URL: `https://dervicblog.github.io/repo/`
2. Open your package manager (Cydia, Sileo, Zebra, etc.).
3. Add a new source and paste the URL.
4. Refresh your sources to see the available packages.

## 📝 Contribution
If you are interested in contributing, reporting bugs, or suggesting new packages to be hosted, feel free to open an *Issue* in this repository.
